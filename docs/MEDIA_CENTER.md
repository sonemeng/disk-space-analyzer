# 媒体管理中心

本文说明 Tauri 6.1 媒体管理中心的分析规则、性能边界和删除安全策略。

## 扫描流程

1. 用户可选扫描类型：**全部 / 仅图片 / 仅视频 / 仅音频**（后端只收集对应扩展名）。
2. 遍历整盘或文件夹；应用排除路径，并跳过 `Windows`、`Program Files`、`node_modules` 等目录。
3. 按扩展名识别媒体（只读元数据，不解码）；遍历进度会持续上报。
4. **按体积优先**深度分析（设置并发数生效）：
   - 图片：最多约 2500 张尺寸/模糊/感知哈希；最大 240 张缩略图
   - 音频：最多约 1500 个时长/码率
   - 视频：最多约 400 个 `ffprobe`
   - 深度分析阶段按完成数推送进度，避免长时间停在同一百分比
5. 同大小且 64KB–2GB 的文件做 SHA-256 重复组；哈希阶段同样推送进度。
6. 对已有感知哈希的图片做相似分组；按大小返回最多 2000 项。

## 图片规则

- 完全重复：文件大小相同且 SHA-256 相同。
- 相似图片：感知哈希距离不大于 10，仅表示视觉结构接近。
- 截图：路径或文件名包含 Screenshot、Screenshots、Screen Shot、Snipping、截图或截屏。
- 可能模糊：对缩小后的灰度图计算拉普拉斯方差，分数低于 55 时标记。
- 超大原图：文件大小达到设置中的大文件阈值。

截图与清晰度都是启发式候选。纯色设计稿、扫描件和浅景深照片可能被标记为模糊，不能据此自动删除。

## 音频与视频

音频通过 `lofty` 读取时长、码率和采样率。FLAC、WAV 和 AIFF 标记为无损格式。

视频始终提供格式、大小、重复与超大筛选。系统能够找到 `ffprobe` 时，额外读取时长、分辨率、视频编码和整体码率；否则界面显示“基础视频元数据”。应用不会下载或静默安装外部解码器。

## 回收站安全

- 前端只能提交已选择的路径，后端会重新验证绝对路径、现存普通文件和媒体扩展名。
- 单次最多处理 1000 个文件。
- 媒体文件只调用系统回收站，不提供永久删除接口。
- “选择重复副本”只适用于 SHA-256 完全重复组；相似图片不会自动选择。
- 回收后汇总数据不会猜测修正，界面会提示重新扫描。

## 隐私

文件路径、哈希、缩略图、清晰度分数和媒体属性均在本机处理。更新检查只访问配置的公开 GitHub Releases API，不上传扫描数据。

## 整盘分析

媒体页顶部可单独选择盘符（可与侧栏当前盘不同），或「选择文件夹」只扫指定目录。

整盘媒体较多时，耗时主要来自：

1. 目录遍历（已跳过系统/依赖目录）  
2. 大图解码与感知哈希  
3. 视频 `ffprobe`  
4. 同大小文件的 SHA-256  

建议：先用「选择文件夹」对准照片/视频库；设置中提高并发、排除无关盘路径。界面只展示最大 2000 项，但统计计数仍覆盖扫描到的全部媒体。
