# 媒体管理中心

本文说明 Tauri 6.0 媒体管理中心的分析规则、性能边界和删除安全策略。

## 扫描流程

1. 遍历用户选择的文件夹，并在进入目录前应用设置中的排除路径。
2. 按扩展名识别常见图片、视频和音频格式。
3. 使用设置中的并发数读取图片与音频属性。
4. 对相同大小的媒体文件计算 SHA-256，形成完全重复组。
5. 对最多 1500 张图片计算 64 位感知哈希，汉明距离不大于 10 时形成相似候选组。
6. 按大小返回最多 2000 个结果，为最大的 240 张图片生成内存缩略图。

## 图片规则

- 完全重复：文件大小相同且 SHA-256 相同。
- 相似图片：感知哈希距离不大于 10，仅表示视觉结构接近。
- 截图：路径或文件名包含 Screenshot、Screenshots、Screen Shot、Snipping、截图或截屏。
- 可能模糊：对缩小后的灰度图计算拉普拉斯方差，分数低于 55 时标记。
- 超大原图：文件大小达到设置中的大文件阈值。

截图与清晰度都是启发式候选。纯色设计稿、扫描件和浅景深照片可能被标记为模糊，不能据此自动删除。

## 音频与视频

音频通过 `lofty` 读取时长、码率和采样率。FLAC、WAV 和 AIFF 标记为无损格式。

视频始终提供格式、大小、重复与超大筛选。系统能够找到 `ffprobe` 时，额外读取时长、分辨率、视频编码和整体码率；否则界面显示“基础视频元数据”。应用不会下载或静默安装外部解码器。

## 回收站安全

- 前端只能提交已选择的路径，后端会重新验证绝对路径、现存普通文件和媒体扩展名。
- 单次最多处理 1000 个文件。
- 媒体文件只调用系统回收站，不提供永久删除接口。
- “选择重复副本”只适用于 SHA-256 完全重复组；相似图片不会自动选择。
- 回收后汇总数据不会猜测修正，界面会提示重新扫描。

## 隐私

文件路径、哈希、缩略图、清晰度分数和媒体属性均在本机处理。更新检查只访问配置的公开 GitHub Releases API，不上传扫描数据。
