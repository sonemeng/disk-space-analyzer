# 产品路线图与任务排程

> 避免后期忘记方向。完成项请勾选；变更时同步改本文与 `CHANGELOG.md`。

## 模块定位（稳定分工）

| 模块 | 职责 |
|------|------|
| 空间概览 | 整盘扫描入口、容量与类别总览 |
| 清理中心 | 白名单/开发可重建执行（回收站） |
| **文件审查** | 空间结构导航：哪里大、可筛、可选、可下钻 |
| **深度分析** | 专项诊断：重复、趋势、年龄 |
| 媒体管理 | 媒体专项 |
| 注册表 | 系统注册表健康（初级/进阶/专家） |

原则：**审查/分析出候选 → 清理中心或回收站执行**；危险一键尽量少。

## 技术备忘

- 删除统一 **回收站**（`trash`），非永久删除。
- 通用文件回收命令：`recycle_paths`（阶段 A 新增，审查/重复共用）。
- 媒体仍可用 `recycle_media`（扩展名校验更严）。
- 前端生产构建必须 `vite base: './'`，否则 Tauri release **白屏**。
- 发版：先 `npm run build`，再 `cargo build --release` 或 `npx tauri build --no-bundle`，覆盖 `项目根/dist/磁盘空间分析器.exe`。

## 阶段 U1 — UI 大改方向（年轻人向）

**目标气质：** 颜色舒适有活力 · 简洁但不简单 · 有动感与互动感  
**受众：** 会用电脑的年轻人，重视第一眼与操作反馈  

**原则（避免花哨）：**
- 主色 1 + 点缀 1～2，背景干净，对比够
- 信息层级清楚：少边框堆砌，多留白与分区
- 动效克制：状态切换 150～250ms，可感知但不拖沓
- 互动：hover/按下/成功反馈明确；下拉帘、卡片可点有反馈
- 组件体系统一：按钮、卡片、表格、空状态同一语言

**版本：** 6.2.0 起进入 U1  
**现有主题保留：** 海盐蓝 / 活力青绿 / 橘子汽水 / 莓果红 / 晴空灰 / 薄荷玫瑰 / 薰衣草青（不再推倒色板，在此上增强）

**落地进度：**
| 步骤 | 内容 | 状态 |
|------|------|------|
| U1.1 | Design tokens + 圆角/阴影/动效节奏 | ✅ 6.2.0 第一版 |
| U1.2 | 侧栏 + 顶栏 sticky 毛玻璃 + 主区背景氛围 | ✅ 6.2.0 第一版 |
| U1.3 | 按钮/卡片/表格/空状态互动反馈 | ✅ 6.2.0 |
| U1.4 | 核心页细调 + 更深玻璃 + 筛选条加宽 | ✅ 6.2.0 第二轮 |
